# Logo licences

Source: Wikimedia Commons only, fetched via the MediaWiki API (`prop=imageinfo&iiprop=url|extmetadata`) on 2026-11-04.
Every file below carries the Commons licence "Public domain" (extmetadata `LicenseShortName: Public domain`, `Copyrighted: False`, `AttributionRequired: false`). On Commons this is the tag used for logos that are below the threshold of originality (e.g. PD-textlogo / PD-ineligible) or released without restriction. No file here is CC-BY or CC-BY-SA, so no attribution is legally required; authors are listed anyway.

**Trademarks.** These are registered trademarks of their owners. A public-domain *copyright* status does not remove trademark rights. Vansales shows them only to identify the makes of vans offered for sale, and does not imply endorsement.

Files were optimised with svgo (metadata, comments and editor data stripped) and, where noted, the viewBox was cropped to the emblem. Artwork is otherwise unmodified.
